# WeLong · Application privacy policies

This repository publishes static pages at https://welong.github.io/ using GitHub Pages. The existing homepage is preserved.

Each application has its own `/<project>/privacy/` directory. Russian is the default (`index.html`); English (`en.html`) and Simplified Chinese (`zh-CN.html`) are available alongside it.

Contact: [apwelong@gmail.com](mailto:apwelong@gmail.com).

Application source code, private data, signing material and build outputs do not belong in this public website repository. Policies must describe each application's actual behavior and be updated when that behavior changes.
