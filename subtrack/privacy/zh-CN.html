Подписки и счета — 隐私政策

生效日期: 2026 年 10 月 28 日

「Подписки и счета」是一款安卓应用，用于记录订阅与周期账单、查看付款日历、接收本地提醒和使用桌面小组件。本政策分别说明应用内的数据使用，以及访问本网页时的数据处理。

1. 无需服务器

应用无需注册，也不连接开发者服务器。应用没有互联网权限、广告、应用内购买、统计 SDK、支付 SDK 或 RuStore 评分 SDK，不会向开发者发送你的记录或应用使用信息。

应用不会连接银行、移动运营商或应用商店获取购买记录，不会执行扣款或取消订阅。服务名称、付款方式和账号信息均由你填写或导入。

2. 设备上的数据及用途

应用的私有存储包含：

  • 订阅与账单记录：名称、金额或金额未知状态、币种、周期、付款日期、结束日期、试用期与取消日期、记录状态、分类、图标、付款渠道、备注、链接和提醒设置。
  • 已付款及已跳过的付款历史、实际金额与日期、付款备注、价格变更历史，以及你填写的未来价格。
  • 付款方式名称与类型、可选的银行卡或手机号码末四位，以及服务账号或缴费户号文本，例如登录名或电子邮箱地址。实际付款可以单独保存当时付款方式、末位数字、账号和付款渠道的快照。
  • 语言、主题、隐藏金额设置、收入日期、小组件设置、本地提醒所需的运行记录和所选 CSV 编码。

这些信息用于显示你的记录、日历、计算结果、分币种统计、发薪日前的付款、本地提醒、小组件，以及你选择的导入与导出，不用于广告或用户画像。

应用不需要完整银行卡号、CVV/CVC 或密码，请勿将其填写在名称、备注或账号字段中。银行卡或手机号码末四位可以留空。

3. 导入、导出和备份

应用通过安卓系统文件选择器选择和保存文件，只读取你选择的文件，或你从其他应用明确分享给它的 CSV 文本。为预览和选择编码，CSV 内容会临时复制到私有缓存；关闭预览或成功导入后会删除工作副本，安卓系统也可能清理缓存。

JSON 备份包含记录、付款与价格历史、未来价格、付款方式目录，以及语言、主题、隐藏金额和收入日期等主要设置，不包含各个小组件设置、提醒安排的运行记录或 CSV 缓存。CSV 导出包含记录与付款行，其中包括备注、付款方式名称、末位数字及账号。这些文件是普通文本，应用本身不会对其加密。

恢复 JSON 时可以合并或替换数据库。替换会删除当前数据库内容并写入所选备份。CSV 在预览确认后仅新增记录，不会恢复付款或价格变更历史。

保存位置和文件提供方由你选择。云盘等文件提供方可能按其自身规则上传或同步所选文件，这与应用本身独立。删除记录或卸载应用不会删除已导出的副本，需另行管理。

4. 提醒与安卓权限

  • 提醒在设备上计算。安卓 13 及以上版本会请求通知权限；拒绝后仍可记录数据、查看日历和统计。
  • 在安卓允许的范围内，精确闹钟和全屏通知权限用于响铃提醒的时间安排与显示。相关权限和设置随系统版本而异，是否开启响铃提醒由你决定。
  • 带有通知的前台服务用于播放提醒声音，相应权限用于振动。这不是录音，应用不请求麦克风权限。你可以停止声音，播放时长上限为两分钟。
  • 应用通过重启以及日期、时间、时区变化等系统事件恢复提醒安排并刷新小组件，不请求联系人、短信、通话记录、位置、相机或整个文件存储的访问权限。

提醒能否送达取决于安卓系统和设备设置。关闭、停止或延后提醒不会确认付款，实际付款只会由你的操作记录。

5. 通知与小组件中可见的信息

名称、日期和金额可能显示在通知、全屏提醒或桌面小组件中。应用会请求私密通知显示方式，但锁屏显示同时取决于安卓设置。小组件会向设备上的桌面启动器提供包含记录信息的渲染图片。

隐藏金额只会在相应界面遮蔽数字金额，不会删除数据或隐藏名称和日期。小组件有独立的隐藏金额设置，请分别检查。此设置不会加密数据库或导出文件。

6. 外部链接和其他应用

你主动选择相关操作时，服务网站、订阅管理、收据历史或本政策可能在浏览器或其他应用中打开。应用会传递目标网址，包括你自行填写的链接，不会自动附带订阅与付款数据库。

外部网站、应用商店、文件提供方和邮件服务可能使用互联网，并按其自身规则处理数据。你在这些服务中的操作及填写的信息，受其条款和政策约束。

7. 保存、修改和删除

本地数据会在你使用期间保留，直至你将其删除。你可以在应用内修改和删除记录。删除订阅或账单会移除相关付款与价格变更历史，也可以单独撤销某次付款状态。

归档记录或付款方式不等于删除。重命名或归档付款方式不会改写已保存的实际付款快照。如不再需要相关信息，可修改对应付款、撤销其状态或删除关联记录。

通过安卓设置清除应用数据，或完整卸载应用及其数据，会移除私有数据库、设置和缓存。应用不会在开发者服务器另存副本。导出文件、文件提供方的副本和你发送的邮件需另行删除。

应用配置已关闭安卓自动备份和设备数据迁移；你可以自行通过 JSON 导出与导入转移数据。我们不承诺恢复已删除的数据，也不保证对存储介质进行物理安全擦除。

8. 本网页

本政策托管于 GitHub Pages。访问网页时，GitHub 会出于安全目的记录访问者的 IP 地址。详情见 GitHub Pages 数据收集说明及 GitHub 隐私声明。

上述处理属于网站访问行为，不属于应用离线运行。本网页无法读取你的记录数据库，也没有添加统计、广告、外部字体、脚本或自有 Cookie。

9. 政策更新

新版政策会在此地址发布并更新日期。如数据处理方式发生变化，我们会更新说明，并在需要时征求同意。
