隐私政策

Мои даты 是一款提供倒数日、正数日、本地提醒和桌面小组件的安卓应用。本政策说明使用哪些数据、数据保存在哪里，以及你如何管理这些数据。

事件和所选背景保存在设备上。评分和评论由 RuStore 处理。

1. 设备上的数据

应用的本地存储包含：

  • 事件标题、日期、备注、计数模式、重复规则、分类、外观和提醒设置。
  • 自建分类、所选图标、语言、主题、小组件设置，以及所选背景的副本。
  • 首次使用时间、事件保存次数和最近一次尝试请求评分的时间，用于限制评分提示的频率。

核心功能可离线使用，无需注册应用账号。内置插画、背景和字体无需下载。应用没有云同步、广告 SDK、内购或开发者自建的统计服务，不使用 Google Play 服务（GMS）或 Firebase。

2. 选择的照片

应用通过安卓系统文件选择器选择图片，只打开你选择的图片，并在设备上完成裁剪。裁剪后的副本保存在应用内部存储中，用作事件或小组件背景。

原始文件不会被修改。原照片中的位置等元数据不会写入新的图片副本。开发者不会收到你选择的照片，应用也不会将其上传到服务器。

3. 提醒与安卓权限

  • 提醒在设备上计算，并通过本地通知显示。安卓 13 及以上版本会为此请求通知权限。拒绝通知权限不影响保存事件和使用小组件。
  • 安卓 8–9 仅在将图片保存到相册时请求存储写入权限。拒绝后，仍可通过其他应用分享图片。
  • 互联网访问用于 RuStore 评分服务，事件不会通过互联网同步。应用还使用安卓系统功能刷新小组件，并在重启后恢复提醒安排。

事件标题和日期可能显示在桌面小组件或锁屏通知中。你可以在安卓设置中调整通知内容的可见性。

4. 图片分享、VK 与相册

你主动分享时，应用会生成包含事件卡片上所示信息的 PNG，并保存到缓存。你选择的接收应用会临时获得这张图片的读取权限。接收应用按照其自身规则处理图片。

VK 按钮会将图片交给已安装的 VK 客户端，由你在其中完成发送或发布。Мои даты 不接入 VK SDK、不登录 VK，也不会自行上传图片。

保存到相册会在 Pictures/Мои даты 中创建独立副本。相册以及其他应用中的副本不会随事件删除或应用卸载而删除。再次使用分享功能时，缓存中超过 24 小时的分享文件可能被清理。

5. RuStore 评分与评论

应用使用 RuStore Review 10.5.2。使用一段时间后，可能显示 RuStore 评分界面。是否提交评分和评论由你决定。设置中也有“在 RuStore 评分”入口，会打开 RuStore 应用页或浏览器。

为提供服务和诊断问题，RuStore 可能处理设备、应用及 SDK 版本、连接状态、服务标识和服务运行事件等技术信息。我们不会向 SDK 传入你的事件标题、日期、备注、照片或事件数据库。

提交的评分和评论由 RuStore 按其用户隐私政策处理。评分界面的可用性取决于网络、RuStore 客户端及其账号。应用的核心功能不要求你参与评分。

6. 保存与删除

你可以在应用中删除事件和自建分类。删除事件会移除其记录。更换背景或删除事件后，已保存的背景副本可能继续保留在内部存储中，因为多个小组件可能共用同一张背景。

通过安卓设置清除应用数据，或完全卸载应用，会移除应用本地存储中的数据库、设置及内部背景副本。相册或已交给其他应用的副本需要另行管理。应用已关闭自动数据备份，没有内置备份与恢复功能。

7. 本网页

本政策托管于 GitHub Pages。访问网页时，GitHub 会出于安全目的记录访问者的 IP 地址。详情见 GitHub Pages 数据收集说明及 GitHub 隐私声明。

上述处理属于网站访问行为。网页无法读取应用中的事件或照片。我们没有在本网页添加统计、广告脚本、外部字体或自有 Cookie。

8. 政策更新

新版本政策会在本页发布，并更新日期。在接入广告、云功能或其他服务前，我们会更新数据处理说明，并在需要时征求同意。
